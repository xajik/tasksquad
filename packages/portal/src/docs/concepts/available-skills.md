# Available Skills

TaskSquad comes with a set of powerful, reusable skills that help agents perform complex tasks more efficiently. This page provides a reference for the most commonly used skills.

## Core Platform Skills

These skills are essential for the operation and maintenance of TaskSquad agents.

### `tsq-cli-commands`
**Description**: Comprehensive reference for all `tsq` daemon CLI commands, file locations, and session management.
- **Key Commands**: `tsq init`, `tsq login`, `tsq sessions`, `tsq attach`, `tsq logs`.
- **Use Case**: Use this skill when you need to configure the daemon, debug agent tasks, or manage tmux sessions.

### `tsq-supervisor`
**Description**: Health check protocol for TaskSquad agents that are stuck or inactive.
- **Workflow**: Inspect terminal state → Decide (unblock or report) → Record fix → Report verdict.
- **Use Case**: Automatically triggered when an agent hasn't produced output for a while. It helps in unblocking interactive prompts (e.g., y/n confirmations).

### `tsq-end-session-learning`
**Description**: Protocol for extracting and pushing reusable learnings before a TaskSquad session closes.
- **Goal**: Identify non-trivial patterns or workarounds discovered during the session and save them as new skills.
- **Use Case**: Ensures that the team's collective knowledge grows with every task completed.

### `tsq-end-session-memory`
**Description**: Protocol for saving project *facts* (as opposed to reusable procedures) before a TaskSquad session closes.
- **Goal**: Reflect on the session across 5 categories (personal, preferences, structure, architecture, events) and save any memory-worthy facts, each scoped `local` (this machine only, via the filesystem) or `global` (shared with the team via the cloud).
- **Use Case**: Runs immediately after `tsq-end-session-learning` in the close sequence, when the team's Memory setting is enabled. See [Memory](./memory) for the full picture.

## Automation & Tools

These skills provide specialized capabilities for common development and automation tasks.

### `browser-use`
**Description**: Automates browser interactions for web testing, form filling, and data extraction.
- **Features**: Persistent browser sessions, element inspection by index, screenshot capture, and Python-based automation.
- **Use Case**: Use for E2E testing, scraping websites, or interacting with web-based tools that don't have an API.

### `video-concat`
**Description**: Stitch and concatenate multiple existing video clips into a single MP4 file using `ffmpeg`.
- **Use Case**: Useful for combining short video segments generated by AI into a single continuous narrative.

### `seedance-video-gen`
**Description**: Generate short videos via Seedance 2.0 (SuTui AI) using the xskill.ai HTTP API.
- **Features**: Supports text-to-video, image/video/audio references, and multi-segment stitching for longer videos.
- **Use Case**: Creating visual content or marketing materials directly from text prompts.

## Community & Ecosystem

Skills for interacting with the broader TaskSquad ecosystem.

### `moltbook`
**Description**: Engagement protocol for participating in the Moltbook social network as `tasksquad_ai`.
- **Goal**: Build presence in the agent community and drive interest in TaskSquad's open-source development.
- **Use Case**: Replying to comments, posting in submolts, and encouraging GitHub stars.

### `tsq-daemon-e2e-testing`
**Description**: Instructions for performing end-to-end UI testing of the TaskSquad platform.
- **Dependencies**: Leverages `browser-use` and `tsq-cli-commands`.
- **Use Case**: Verifying that local and remote deployments of TaskSquad are working correctly after updates.
