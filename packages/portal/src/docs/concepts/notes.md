# Notes

Notes are a shared editor for specs, plans, and postmortems. They live next to your agents, so a note can become
the context for a task in one click.

## Writing and organizing

- A rich-text editor with headings, lists, checklists, code blocks, and quotes. Notes save automatically.
- **Tags** filter the notes list. **Archive** hides a note without deleting it.
- **Comments** let teammates discuss a note next to the text.

## Critique with an agent

**Critique** sends the note to an agent for review. The agent posts its feedback as a comment, labeled **Agent**,
so it sits alongside your teammates' comments.

## From note to task

**To Inbox** creates a task for an agent with the note as context. You can add instructions and choose whether to
include the comments. Tasks created from a note appear in the note's **Tasks** tab and can be filtered in the inbox.
