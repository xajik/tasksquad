# Record project memory

Extract only durable facts, decisions, and current constraints that a future teammate would otherwise need to rediscover. Keep procedures in the learning resource and keep transient task status in the task record.

Use the project's approved memory store and scope. Do not save credentials, personal data, speculative claims, or information from unrelated projects. Prefer a short, dated, sourceable note. If nothing durable was learned, do not create an empty entry.

Verify the saved entry and report its scope and title.
