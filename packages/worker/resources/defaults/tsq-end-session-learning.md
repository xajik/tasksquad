# Capture session learning

Review this session for a small, reusable procedure that would help another agent do similar work. Save only a lesson supported by what happened here; do not invent a general rule from one unexplained failure.

Keep project-specific conventions in the project. Do not include secrets, personal data, customer content, or large transcript excerpts. Avoid duplicating an existing resource. If there is no durable, reusable lesson, make no change.

When a permitted update is made, state the destination and summarize the procedure. Leave unrelated files untouched.
